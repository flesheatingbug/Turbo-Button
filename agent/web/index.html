Relay server

Your own turbo-relay server lets the phone reach PCs that aren't on the same Wi-Fi: remote-desktop jobs and office PCs. To pair: sign in to the relay's web page, tap Pair a phone, then Pair with relay here and scan the code. Everything sent through it is end-to-end encrypted.

Notifications

Only while Turbo Button isn't on screen. While jobs run, a quiet "working" notification keeps the app awake so the alert still arrives with the screen off.

App updates

New builds come from the GitHub release page. The app checks when it opens and twice a day in the background, then asks before downloading and installing.

Stress test

Loads the CPU hard to shake out overheating, throttling or crashes. Watches the temperature and stops early at 97 C. Changes nothing; tap Stop on the Fix tab to end it any time.

Deep checks · optional, 10–30 min

Read-only checks that run in the background: pending Windows updates, outdated programs, system-file and Windows-image corruption, file-system errors, a malware quick scan and what's filling the disk. Worth it for slow, crashing or possibly infected PCs. Results feed into the plan.
